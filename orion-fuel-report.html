Orion Fuel Report

Upload the monthly Orion "Customer Hours" work order export. This matches each work order day to the asset's real recorded fuel consumption in FleetMagnify and totals it — for the Orion diesel price fluctuation credit.

ℹ️

Method: for every (asset, date) in the Orion file, litres = actual km driven that day (from telematics odometer readings) × the asset's calibrated travel rate, plus that day's actual idle hours × the asset's calibrated idle rate. This is real, calibrated fuel data — not a flat assumed rate — so totals will move month to month as driving and idle patterns change.

Same-day, multiple work orders: if a truck shows on more than one Orion work order on the same date, that day's litres are split between them by Vehicle Hours share. flagged in the table

🔒
This report is only available on the directors' fleet account.
